# Gömülü Yazı Tipleri

Bu klasördeki yazı tipleri, Hüma Native GUI kütüphanesinin (`crates/huma-core/src/gui.rs`)
Dear ImGui tabanlı arayüzünde Türkçe karakterlerin (ş, ğ, ı, İ, ü, ö, ç vb.) doğru
render edilebilmesi için ikili (binary) olarak gömülür (`include_bytes!`).

- `NotoSans-Regular.ttf` — gövde metni
- `NotoSans-Bold.ttf` — `"kalın"` etiket stili ve başlık fontu
- `NotoSans-Italic.ttf` — `"eğik"` etiket stili

**Kaynak:** [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans) (Google Fonts / Noto Project)
**Lisans:** SIL Open Font License 1.1 (bkz. `OFL.txt`) — gömülü kullanım serbesttir.
